# general fusion

- [通用融合基础知识](basics.md)：>本节内容为通算融合算子的理论背景和开发指导，学习本节内容之前，请确保已经掌握矩阵编程和《HCCL集合通信库》中的相关知识。
- [特性场景](feature_scenarios.md)：为避免执行通信任务的环境中硬件闪断导致发生通信中断，通算融合算子可通过配置编译宏与环境变量，开启重执行能力。通算融合算子开启重执行后，AI CPU在检测到环境异常时，通过下图示意的机制，通知AI Core重新下发通信任务，避免由于硬件闪断造成的通信中断，提升通信稳定性。
- [通用融合算子实现](operator_impl.md)：在通算融合类算子的实现中，通信操作使用Hccl高阶API，矩阵乘计算操作使用Matmul高阶API。关于更多集合通信的内容和相关概念请参考《HCCL集合通信库》。通算融合算子的开发过程与一般算子相同，但请注意，当前通算融合算子暂不支持Kernel直调和入图（GE图）开发，仅支持单算子API调用。
