# 2201 to 3510 guide

- [高阶API迁移指导](advanced_api_migration.md)：Ascend C高阶API基本兼容NPU架构版本3510与NPU架构版本2201，部分API进行了扩展。当前3510架构不支持卷积计算类高阶API。
- [基础API迁移指导](basic_api_migration.md)：本节针对NPU架构版本3510的芯片变更对基础API兼容性产生的影响进行说明，并提供基础API的兼容性适配方案。
- [算子编译迁移指导](op_compilation_migration.md)：进行算子编译时，开发者需要感知不同架构、不同的AI处理器型号。
