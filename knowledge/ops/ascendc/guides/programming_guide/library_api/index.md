# 类库API

- [advanced api](advanced_api/index.md)：高阶API基于单核对常见算法进行抽象和封装，实现了一些常用的计算算法，旨在提高编程开发效率。高阶API一般通过调用多种基础API实现。高阶API包括数学计算、矩阵计算、激活函数等API。（共 3 张知识卡，分布在 1 个子目录）
- [basic api](basic_api/index.md)：基础API实现对硬件能力的抽象，开放芯片的能力，保证完备性和兼容性。标注为ISASI（Instruction Set Architecture Special Interface，硬件体系结构相关的接口）类别的API，不能保证跨硬件版本兼容。（共 5 张知识卡，分布在 2 个子目录）
- [编程接口概述（库API）](programming_interface_overview.md)：>本章提供编程API的概述。具体API参考见Ascend C API。
- [Utils API（库API）](utils_api.md)：Ascend C开发提供了丰富的通用工具类，涵盖标准库、平台信息获取、上下文构建、运行时编译及日志输出等功能，支持开发者高效实现算子开发与性能优化。
