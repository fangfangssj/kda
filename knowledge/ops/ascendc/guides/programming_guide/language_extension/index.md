# 语言扩展层

- [SIMD BuiltIn关键字](simd_builtin_keywords.md)：如其他语言一样，会提供一些内置的宏方便用户编写程序。预定义宏一节着重介绍一些用户在做异构编程时会经常用到的宏，以及宏的解释。
- [SIMD语言扩展层C API](simd_language_extension_c_api.md)：C API开放芯片完备编程能力，支持以数组形式分配内存，一般基于指针编程。提供与业界一致的C语言编程体验。
- [SIMD&SIMT BuiltIn关键字](simd_simt_hybrid_builtin_keywords.md)：SIMD与SIMT混合编程使用的函数执行空间限定符与SIMD编程一致，详细说明请参见SIMD BuiltIn关键字的函数执行空间限定符。
- [SIMT BuiltIn关键字](simt_builtin_keywords.md)：函数执行空间限定符（Function Execution Space Qualifier）指示函数是在Host侧执行还是在Device侧执行，以及能被调用的空间范围。
