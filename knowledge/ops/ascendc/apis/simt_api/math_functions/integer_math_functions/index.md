# 整型数学库函数

- [__brev（整数数学函数）](_brev.md)：将输入数据的位序反转，返回反转后的值。
- [__byte_perm](_byte_perm.md)：由输入的两个4字节的uint32_t类型数据组成一个8个字节的64比特位的整数，通过选择器s指定选取其中的4个字节，将这4个字节从低位到高位拼成一个uint32_t类型的整数。具体实现逻辑如下：
- [__clz（整数数学函数）](_clz.md)：从输入数据的二进制最高有效位开始，返回连续的前导零的位数。
- [__ffs（整数数学函数）](_ffs.md)：从二进制输入数据的最低位开始，查找第一个值为1的比特位的位置，并返回该位置的索引，索引从1开始计数；如果二进制数据中没有1，则返回0。
- [__hadd（整数数学函数）](_hadd.md)：获取int32类型数据x和y的平均值，避免中间求和溢出。
- [__mul24（整数数学函数）](_mul24.md)：获取int32类型数据x和y的低24位乘积的低32位运算结果。x和y的高8位数据被忽略。
- [__mul64hi](_mul64hi.md)：获取输入int64类型数据x和y乘积的高64位。
- [__mul_i32toi64](_mul_i32toi64.md)：计算输入32位整数x和y的乘积，返回64位结果。
- [__mulhi（整数数学函数）](_mulhi.md)：获取输入int32类型数据x和y乘积的高32位。
- [__popc（整数数学函数）](_popc.md)：统计输入数据从二进制的高位到低位比特位为1的数量。
- [__rhadd（整数数学函数）](_rhadd.md)：获取int32类型数据x和y的向上取整平均值，避免中间求和溢出。
- [__sad（整数数学函数）](_sad.md)：对输入数据x、y、z，计算 x - y + z的结果，即前两个输入作差的绝对值与第三个输入的和。
- [__uhadd（整数数学函数）](_uhadd.md)：获取uint32类型数据x和y的平均值，避免中间求和溢出。
- [__umul24](_umul24.md)：获取uint32类型数据x和y的低24位乘积的低32位运算结果。x和y的高8位数据被忽略。
- [__umul64hi](_umul64hi.md)：获取输入uint64类型数据x和y乘积的高64位。
- [__umulhi](_umulhi.md)：获取输入uint32类型数据x和y乘积的高32位。
- [__urhadd](_urhadd.md)：获取uint32类型数据x和y的向上取整平均值，避免中间求和溢出。
- [__usad（整数数学函数）](_usad.md)：对输入数据x、y、z，计算 x - y + z的结果，即前两个输入作差的绝对值与第三个输入的和。
- [labs（整数数学函数）](labs.md)：获取输入数据的绝对值。
- [llabs（整数数学函数）](llabs.md)：获取输入数据的绝对值。
