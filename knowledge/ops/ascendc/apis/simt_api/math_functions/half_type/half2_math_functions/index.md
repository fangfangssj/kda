# half2类型数学库函数

- [H2Ceil](h2ceil.md)：获取大于或等于输入数据各元素的最小整数值。
- [H2Cos](h2cos.md)：获取输入数据各元素的三角函数余弦值。
- [H2Exp](h2exp.md)：指定输入x，对x的各元素，获取e的该元素次方。
- [H2Exp10](h2exp10.md)：指定输入x，对x的各元素，获取10的该元素次方。
- [H2Exp2](h2exp2.md)：指定输入x，对x的各元素，获取2的该元素次方。
- [H2Floor](h2floor.md)：获取小于或等于输入数据各元素的最大整数值。
- [H2Log](h2log.md)：获取以e为底，输入数据各元素的对数。
- [H2Log10](h2log10.md)：获取以10为底，输入数据各元素的对数。
- [H2Log2](h2log2.md)：获取以2为底，输入数据各元素的对数。
- [H2Rcp](h2rcp.md)：获取输入数据x各元素的倒数。
- [H2Rint](h2rint.md)：获取与输入数据各元素最接近的整数，若存在两个同样接近的整数，则取其中的偶数。
- [H2Rsqrt](h2rsqrt.md)：获取输入数据x各元素的平方根的倒数。
- [H2Sin](h2sin.md)：获取输入数据各元素的三角函数正弦值。
- [H2Sqrt](h2sqrt.md)：获取输入数据x各元素的平方根。
- [H2Tanh](h2tanh.md)：获取输入数据各元素的三角函数双曲正切值。
- [H2Trunc](h2trunc.md)：获取对输入数据各元素的浮点数截断后的整数。
