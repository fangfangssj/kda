# half类型数学库函数

- [Hceil](hceil.md)：获取大于或等于输入half数据的最小整数值。
- [Half数学函数hcos](hcos.md)：获取输入数据的三角函数余弦值。 !
- [Half数学函数hexp](hexp.md)：指定输入x，获取e的x次方。 !
- [Hexp10](hexp10.md)：计算half输入x的10的x次方。
- [Hexp2](hexp2.md)：计算half输入x的2的x次方。
- [Hfloor](hfloor.md)：获取小于或等于输入half数据的最大整数值。
- [Half数学函数hlog](hlog.md)：获取以e为底，输入数据的对数。 !
- [Hlog10](hlog10.md)：计算half输入数据以10为底的对数。
- [Hlog2](hlog2.md)：计算half输入数据以2为底的对数。
- [Half数学函数hrcp](hrcp.md)：获取输入数据x的倒数。 !
- [Hrint](hrint.md)：获取与输入half数据最接近的整数，若存在两个同样接近的整数则取偶数。
- [Hrsqrt](hrsqrt.md)：计算half输入数据x的平方根的倒数。
- [Half数学函数hsin](hsin.md)：获取输入数据的三角函数正弦值。 !
- [Hsqrt](hsqrt.md)：计算half输入数据x的平方根。
- [Htanh](htanh.md)：计算half输入数据的双曲正切值。
- [Htrunc](htrunc.md)：获取对输入half数据浮点数截断后的整数。
