# 地址空间转换函数

- [__cvta_generic_to_global](_cvta_generic_to_global.md)：将输入的指针转换为其指向的Global Memory内存空间的地址值并返回。
- [__cvta_generic_to_local](_cvta_generic_to_local.md)：将输入的指针转换为其指向的栈空间的地址值并返回。
- [__cvta_generic_to_ubuf](_cvta_generic_to_ubuf.md)：将输入的指针转换为其指向的Unified Buffer内存空间的地址值并返回。
- [__cvta_global_to_generic](_cvta_global_to_generic.md)：将Global Memory内存空间的地址值转换为对应的指针并返回。
- [__cvta_local_to_generic](_cvta_local_to_generic.md)：将栈空间的地址值转换为对应的指针并返回。
- [__cvta_ubuf_to_generic](_cvta_ubuf_to_generic.md)：将Unified Buffer内存空间的地址值转换为对应的指针并返回。
