# Release Notes

- [Cann9ReleaseNotes](cann_9_0_0.md)：CANN 9.0.0首次面向Ascend 950PR/950DT提供试验性C语言扩展层SIMD API，覆盖数据搬运、标量操作、矩阵计算、同步控制等能力。
- [C API](cann_9_1_0.md)：CANN 9.1.0继续完善Ascend 950PR/Ascend 950DT（3510架构）C API，新增矢量计算、数据搬运、标量操作、矩阵计算、同步控制、系统变量和缓存控制接口，并修复9.0.0中的函数命名、类型声明和地址自更新签名问题。

- [C API](cann_9_2_0.md)：CANN 9.2.0在CANN 9.1.0的基础上继续增强C API。本版本新增矩阵与数据搬运配置、Reg计算与搬运、缓存和特殊寄存器控制等能力，为大量Reg接口补充函数返回值形式的重载，并统一公共头文件、接口命名和参数类型。同时，部分旧命名、隐式位置重载和同步复合接口进入废弃期。
