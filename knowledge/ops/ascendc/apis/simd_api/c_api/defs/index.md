# 基础定义

- [常量](constant/index.md)：共 2 张知识卡（如 ASC_C_API_MRGSORT_ELEMENT_LEN、ASC_VDEQ_SIZE）。
- [枚举](enum/index.md)：共 14 张知识卡（如 asc_channel_pad_mode、asc_dual_dst_mode、asc_hf32_round_mode 等）。
- [寄存器类型](type/index.md)：共 2 张知识卡（如 Reg数据类型定义、寄存器类型）。
- [联合体](union/index.md)：共 5 张知识卡（如 asc_fill_value_config、asc_l13d_fmatrix_config、asc_load3d_v2_config 等）。

- [macro](macro/index.md)：共 2 张知识卡（如 ASC_DEPRECATED、ASC_IS_AIC/ASC_IS_AIV）。
