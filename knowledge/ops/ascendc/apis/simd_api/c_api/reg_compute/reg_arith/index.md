- [asc_sub](asc_sub.md)：该接口根据mask，对源操作数src0、src1进行按元素求差操作，将结果写入目的操作数dst。
- [asc_subc](asc_subc.md)：该接口根据mask，对源操作数src0、src1及输入进位carry_src进行按元素求差操作，减法运算在硬件底层通过补码加法实现，将结果写入目的操作数dst，同时将每个元素的进位结果写入carry（存放进位标志的掩码寄存器）。
