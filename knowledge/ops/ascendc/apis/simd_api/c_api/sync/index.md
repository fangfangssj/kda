# 同步控制

- [系统同步能力概述](system_sync_overview.md)：在编程中，同步是指协调多个执行单元（如线程、进程等）对共享资源的访问顺序和时机来确保程序的正确性。如果没有同步来严格控制执行顺序，则会出现结果不一致、行为不可预测等多种问题。

- [inter core sync](inter_core_sync/index.md)：共 10 张知识卡（如 asc_sync_block_arrive、asc_sync_block_wait、asc_sync_inter_arrive 等）。
- [intra core sync](intra_core_sync/index.md)：共 11 张知识卡（如 asc_lock、asc_sync、asc_sync_data_barrier 等）。
