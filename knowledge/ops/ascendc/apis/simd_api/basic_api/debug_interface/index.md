# 调试接口

- [CPU孪生调试](cpu_twin_debug/index.md)：共 5 张知识卡（如 GmAlloc、GmFree、IcpuRunKf 等）。
- [关闭ASCENDC_DUMP说明](disable_ascendc_dump.md)：调试接口（如本章的上板打印、异常检测接口）开启后会对算子性能产生一定影响，通常在调测阶段使用，生产环境建议关闭。ASCENDC_DUMP宏定义是控制调试接口打印的开关。
- [异常检测](exception_detection/index.md)：共 2 张知识卡（如 CheckLocalMemoryIA、Trap）。
- [上板打印](onboard_print/index.md)：共 3 张知识卡（如 DumpAccChkPoint、DumpTensor、PrintTimeStamp）。
- [性能统计](performance_stats/index.md)：共 3 张知识卡（如 MarkStamp、MetricsProfStart、MetricsProfStop）。
