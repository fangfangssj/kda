# 资源管理

- [自定义TBufPool](custom_t_buf_pool/index.md)：共 8 张知识卡（如 ExternImplBufpool、GetBufHandle、GetCurAddr 等）。
- [GetTPipePtr](get_t_pipe_ptr.md)：获取创建TPipe对象时设置的全局唯一TPipe指针，获取后可进行TPipe相关的操作如InitBuffer。

- [TBufPool](t_buf_pool/index.md)：共 5 张知识卡（如 InitBufPool、InitBuffer、Reset 等）。
- [TPipe](t_pipe/index.md)：共 15 张知识卡（如 AllocEventID、Destroy、DestroyWithoutPipeAll 等）。
- [TQue](t_que/index.md)：共 9 张知识卡（如 AllocTensor、DeQue、EnQue 等）。
- [TQueBind](t_que_bind/index.md)：共 13 张知识卡（如 AllocTensor、DeQue、EnQue 等）。
- [TSCM](tscm/index.md)：共 5 张知识卡（如 AllocTensor、DeQue、EnQue 等）。
- [workspace](workspace/index.md)：共 3 张知识卡（如 GetSysWorkSpacePtr、GetUserWorkspace、SetSysWorkSpace）。
