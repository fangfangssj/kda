# BitwiseXor接口

- [BitwiseXor](bitwise_xor.md)：逐比特对两个输入进行异或操作。 !
- [GetBitwiseXorMaxMinTmpSize](get_bitwise_xor_max_min_tmp_size.md)：用于在Host侧获取BitwiseXor接口所需的最大和最小临时空间大小，作为Tiling参数传递到Kernel侧使用。
- [GetBitwiseXorTmpBufferFactorSize](get_bitwise_xor_tmp_buffer_factor_size.md)：获取BitwiseXor接口所需的maxLivedNodeCount和extraBuf，用于在固定临时空间下推算算子单次最大计算元素数量。
