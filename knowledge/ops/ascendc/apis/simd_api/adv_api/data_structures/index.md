# 数据结构

- [数据结构](data_structures.md)：汇总高阶API在Host侧Tiling接口中使用的Ascend C公共类型，包含TensorShape、TensorDataType等数据结构定义。
- [TensorDataType](tensor_data_type.md)：AscendC::TensorDataType是ge::DataType的类型别名，用于描述高阶API的Host侧Tiling接口使用的Tensor数据类型。 具体使用请参考ge::DataType。
- [TensorShape](tensor_shape.md)：AscendC::TensorShape是ge::Shape的类型别名，用于描述高阶API的Host侧Tiling接口使用的Tensor形状。 具体使用请参考ge::Shape。
