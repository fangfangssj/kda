# TensorDataType<a id="tensordatatype"></a>

## 功能说明

`AscendC::TensorDataType`是`ge::DataType`的类型别名，用于描述高阶API的Host侧Tiling接口使用的Tensor数据类型。

具体使用请参考[ge::DataType](https://gitcode.com/cann/metadef/blob/master/docs/zh/api/ge_namespace/DataType.md)。
